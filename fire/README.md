# מהמדורה למעצמה 🔥

תת-גרסה של מגדל האגדות: משחק הישרדות ובנייה לנייד. עידן האבן — מדורה ושלושה אנשים בחושך, ומשם (בהדרגה) עד טירת ה-AI ברמה 50.

**לשחק:** https://meirbal.github.io/tower/fire/ · גם מכפתור בתפריט של כיבוש הממלכות.

- `js/engine.js` — כל הכלכלה והזמן (בלי DOM). יחידת זמן = דקה אמיתית; `advance` משלים את הזמן שעבר כשהמשחק היה סגור. כל המספרים ב-`CFG`, `LEVELS`, `RESEARCH`, `BUILD`, `RECIPES`.
- `js/game.js` — מפה בקנבס (אור/חושך, משלחות, אויבים), לוחות (שבט, תיבה, מחקר, בנייה, יומן), שמירה ב-`localStorage` (`fire_save_v1`).
- `tools/balance.js` — בוט שמשחק כמו שחקן (נכנס כל ~3 שעות ביום) ומדווח מתי הגיע לכל רמה: `node fire/tools/balance.js [seed] [days]`.

הגרסה הנוכחית: ליבה + רמות 1–10 (מדורה → עיר קטנה).
