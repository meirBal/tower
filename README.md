# מגדל האגדות 🏰

משחק הגנת מגדל לנייד בעברית — דמות, מגדל, חיילים, קסמים, עמדות הגנה ושני עולמות.

**לשחק ולהתקין לטלפון:** https://meirbal.github.io/tower/
- אנדרואיד (כרום): כפתור **📲 הורד לטלפון** במסך הפתיחה → התקן
- אייפון (ספארי): שיתוף ← **הוסף למסך הבית**

אחרי ההתקנה המשחק נפתח מהאייקון במסך מלא, עובד גם בלי אינטרנט, והכפתור נעלם.

התיקייה הזו היא תוצר בנייה (`build.py` → `dist/pages/`). קוד המקור, הבדיקות והגרסאות — בפרויקט המקור.
