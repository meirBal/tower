# כיבוש הממלכות ⚔️

תת-גרסה של מגדל האגדות: משחק אסטרטגיה לנייד. גוררים צבאות ממחוז למחוז, כובשים את המפה, לבד נגד בוטים או עם עד 8 חברים.

**לשחק:** https://meirbal.github.io/tower/conquest/  ·  חדר עם חברים: `?room=קוד`

- `js/engine.js` — הסימולציה (מפה מזרע, גדילה, מסלולים דרך השטח שלך, קרבות, בוטים). רץ גם ב-node לבדיקות איזון.
- `js/net.js` — Supabase Realtime Broadcast (אותו פרויקט ומפתח ציבורי של מגדל האגדות), ערוץ `conquest-<קוד>`. `?net=local` = BroadcastChannel לבדיקות בין לשוניות.
- `js/game.js` — ציור, מגע (גרירה, הקשה, צביטה לזום), מסכים, רב-משתתפים.
- רב-משתתפים: המארח מריץ את המשחק ומשדר מצב 5 פעמים בשנייה; המשתתפים שולחים פקודות. אם המארח נעלם — הבא בתור ממשיך מהמצב האחרון. שחקן שהתנתק מוחלף בבוט וחוזר כשהוא מתחבר.
- שם ומזהה מכשיר משותפים עם מגדל האגדות (`td_playerName`, `td_deviceId`).
- טבלת אלופים: `supabase/conquest_scores.sql` (טבלה `conquest_scores` ותצוגה `conquest_leaderboard`).
